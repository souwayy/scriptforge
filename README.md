ScriptForge // Python & OSINT Tools

Здесь собраны мои утилиты на Python для OSINT-исследований, автоматизации и кибербезопасности.

Все инструменты работают через терминал (командную строку) и имеют подробные инструкции по запуску.

Инструменты

Kairos

Асинхронный OSINT-сканер для поиска цифрового следа по никнейму. Проверяет 500+ площадок, собирает метаданные и генерирует HTML/JSON отчеты.

· Стек: Python, asyncio, aiohttp.
· Инструкция: Перейти в папку Kairos

NumHunter

Анализатор номеров телефонов. Определяет страну, регион, оператора связи и тип линии. Работает с офлайн-базами.

· Стек: Python.
· Инструкция: Перейти в папку NumHunter
